Overview

Four Interoperable Artifacts

The rapid proliferation of AI music generators has outpaced the availability of structured, richly annotated datasets for studying them. Existing benchmarks are small, cover only one or two generators, lack human perceptual data, or rely on proprietary audio. REDACTED-Tunes closes this gap at scale.

Search Infrastructure

The corpus ships with a production-ready FastAPI server and a dark-mode web UI with Simple and Advanced search modes — including vector similarity, BM25 text search, two-stage refinement, and audio-upload similarity via the Music-Whisper encoder.

# Quick start (HF_TOKEN needed for google/embeddinggemma-300m)
pip install fastapi uvicorn faiss-cpu numpy pandas sentence-transformers \
            torch scipy tqdm python-multipart transformers

# → http://localhost:7860
Model

REDACTED-Music-Whisper

A fine-tuned version of OpenAI Whisper Small trained for music captioning. The model generates detailed, paragraph-length descriptions of audio tracks and was used to annotate 1,356,009 tracks (94.8%) in the corpus.

RPG Subset

REDACTED-RPG

A curated subset of 2,580 instrumental tracks from the corpus (Suno + Udio), annotated at full audio length by Gemini 3 Flash Preview with structured gameplay situations across 18 RPG genre categories.

18 RPG Genres

High Fantasy Low / Gritty Fantasy Dark Fantasy Mythic / Ancient World Medieval Historical Renaissance / Pirate Age Wild West Gothic Horror Cosmic Horror Modern Supernatural Modern Realistic Superhero Post-Apocalyptic Cyberpunk Hard Sci-Fi Space Opera Science Fantasy Alternate History
Situation-based search: Query "sneaking through a dark dungeon" — the server embeds the query with EmbeddingGemma 300M and retrieves the most situationally-matched tracks from per-genre FAISS indices (39,605 situation vectors total).

Human Annotation Study

Annotations collected via a purpose-built web platform across two phases (591 trials, 61 participants, mean age 29.4 yrs). Each trial included an authenticity assessment, familiarity rating, five continuous perceptual dimension sliders (1–10), and optional free-text comments.

Key finding — quality–authenticity halo effect: Human songs score higher on all five quality dimensions, yet human-detection accuracy is only 64.3%. Higher perceived quality does not reliably predict a "real" verdict. Udio's near-chance detection rate (41.4%) indicates perceptual near-parity with human recordings on the production quality axis.
